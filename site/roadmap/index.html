Available now

Native alpha.11.

The downloadable developer preview includes exact arithmetic, checked domain types, records and enums, generics, persistent collections, purity checks, compiler inspection tools and bounded async TCP on native hosts. It uses bytecode v9. Namespace execution is unavailable.

Native: 0.1.0-alpha.11 for Ubuntu 22.04+ x86-64 and macOS 14+ Apple silicon. Browser: separately pinned v0.1.1, with no host filesystem, process or raw TCP access. Use the matching compiler and VM when running saved bytecode.
