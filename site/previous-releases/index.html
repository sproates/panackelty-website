Previously released

What alpha.13 introduced.

Reusable local packages, native HTTP and a static file server arrived, together with a broader view of the compiler’s recorded decisions.

Released · native

HTTP client and server

Bounded HTTP/1.1 GET and verified HTTPS, typed responses and errors, and a cleartext GET/HEAD/POST server with explicit limits and graceful shutdown. Server TLS remains outside the contract.

Released

Local reusable packages

Strict manifests, dependency aliases and public exports let applications share local libraries. Move the complete package tree together and pin the matching toolchain. Remote restoration is not included.

Create two small local packages →
Released · native tool

Serve files over HTTP

The installed panack-http-server serves files from any chosen directory over HTTP, with confined asynchronous reads, directory indexes and MIME types. Website preview is one use case; optional no-cache and noindex headers support it. It has bounded responses and no watching, rebuilds or server TLS.

Previously released

What alpha.12 adds.

Alpha.12 delivers the three outcomes planned for this release. The downloadable native preview is available for supported Linux x86-64 and Apple silicon systems; the browser toolchain remains separately pinned.

Released

Repeated else if

Write flat conditional chains with multiple else-if arms and an optional final else. Conditions run in order and only the selected branch executes.

Released · measured scope

Panackelty source coverage

Opt-in inventory, collection, aggregation and reporting commands measure compiler, bytecode and standard-library source. The original alpha.12 baseline covered 43 files across explicit roots, not the whole test suite. Current reports identify their own revision and scope.

Released · scoped support

Executable namespaces

Use project and standard-library imports, aliases, selected imports, qualified names, public declarations and re-exports. Alpha.12 did not include packages or remote dependencies; alpha.13 adds local packages. Incomplete checks reject.
