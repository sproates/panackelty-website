An experimental programming language

Exact values.
Clear intent.

Small programs should be easy to write. Growing programs should remain easy to reason about. Panackelty brings exact numbers, checked domain types and explicit effects to a compact compiled language.

Try it in your browser → Get started

Developer preview 0.1.0-alpha.11 is available for Linux x86-64 and Apple silicon.

exact.panackalpha.11

main(): Void {
  third = 1/3
  print((third * 30).nat())
  print((1/8).dec())
}
$ panack run exact.panack

10
0.125

Exact fractions, exact conversions. An unrepresentable exact conversion fails instead of silently rounding.

What makes it different

Small syntax.
Substantial semantics.

01 / Values

Numbers that stay exact

Arbitrary-precision Nat and Int, exact base-10 Dec and rational Rat values let you work without silently substituting floating-point approximations. Conversions make representability explicit.

Explore numeric semantics →
02 / Domain modelling

Rules belong with the type

Guarded types attach constraints to values: a positive count, a bounded port, a valid domain value. Records, enums, generics, Option and Result help describe both successful values and failure cases.

See a guarded type →
03 / Effects

Make side effects visible

A pure function cannot perform I/O or call effectful code. Keep calculations separate from interactions with the outside world, with the compiler enforcing that boundary.
