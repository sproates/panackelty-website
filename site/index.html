Why this project

Why I’m building Panackelty.

Why would someone use Panackelty? Maybe they wouldn’t, and that’s fine. If you don’t like Panackelty or don’t think it solves anything for you, use something else.

It would be awesome if someone did find Panackelty useful! But that’s not the primary goal. If that were the aim, I’d point the project more directly at things developers really want right now, like performance or rapid development.

I’ve been programming since I was a kid, and I never really wanted to build games or turn the lights on and off in my house. I’ve always been much more interested in what can be done with programming languages, and what we can express in them. Building Panackelty gives me a way to explore those questions directly. There’s a bit of “because it’s there” in that too.
