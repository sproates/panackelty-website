API stability during alpha

APIs may change between alpha releases without advance notice. The released HTTP references follow alpha.15. The separately labelled development section describes the upcoming alpha.16 stdlib; those APIs are not available in the current release or browser playground.

From the first non-alpha release, each release will have its own versioned documentation, with breaking changes documented and managed through the release process.
