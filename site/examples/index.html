Alpha.11 example

Give a business rule a name

Positive expresses a constraint on an integer. Code receiving this type can state its expectation directly.


type Positive = Int where value > 0

pure triple(n: Positive): Int {
  n * 3
}

main(): Void {
  answer: Positive = 14
  print(triple(answer))
}

Output


42
Works with alpha.11

Exact fractions, explicit conversions

exact.panackalpha.11

main(): Void {
  third = 1/3
  print((third * 30).nat())
  print((1/8).dec())
}
$ panack run exact.panack

10
0.125

Exact fractions, exact conversions. An unrepresentable exact conversion fails instead of silently rounding.
