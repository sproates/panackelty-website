A complete program

Hello, Ada.

Works with alpha.11

A pure calculation, an effectful entry point

The greeting produces a value. main prints it. String interpolation keeps the result readable.


pure greeting(name: Str, answer: Nat): Str {
  "Hello, ${name}. The answer is ${answer}."
}

main(): Void {
  print(greeting("Ada", 42))
}

Output


Hello, Ada. The answer is 42.

From download
to “Hello, Ada.”

Start with developer preview 0.1.0-alpha.11. It includes the command, VM, compiler and standard library. Initial downloads support Ubuntu 22.04 or newer on x86-64 and macOS 14 or newer on Apple silicon; Windows is not part of this preview.

Optional installation route

Install with one command

The installer selects 0.1.0-alpha.11 for the supported Ubuntu x86-64 and macOS Apple silicon versions above. It verifies the release checksum and installs in your home directory without sudo. Inspect the script before running it; the installer guide explains trust, version selection, upgrades and removal.

curl --proto '=https' --proto-redir '=https' --tlsv1.2 --fail --location --show-error https://raw.githubusercontent.com/sproates/panackelty/ab8e3ad880c158c171c2a13b5cd3cd775dd4c745/scripts/install.sh | sh -s -- --version 0.1.0-alpha.11

After installation, add the command to this shell’s PATH:

export PATH="$HOME/.local/bin:$PATH"

The script never edits shell startup files. This PATH change applies to the current shell. You can also invoke "$HOME/.local/bin/panack" directly.

Run your first program

Save the greeting above as hello.panack in a directory you own, then check and run it. The optional final two commands save and run bytecode.

panack --version
panack check hello.panack
panack run hello.panack
panack compile hello.panack -o hello.bc
panack run hello.bc

Both runs print Hello, Ada. The answer is 42.

Prefer a manual download? Show download and verification steps

This is an alternative to the one-command installer. Follow it if you prefer to download, verify and extract the archive yourself.

  1. Download and verify

    Start in a new, empty directory you own. You need a terminal with Bash or zsh, curl, tar and your platform's SHA-256 utility. Copy the complete block for your platform to download the archive and matching checksum from the alpha.11 release. No administrator permissions or source checkout are needed.

    Linux x86-64
    (
  set -eu
  release=https://github.com/sproates/panackelty/releases/download/v0.1.0-alpha.11
  archive=panackelty-0.1.0-alpha.11-linux-x86_64.tar.gz
  curl --fail --location --show-error --output "$archive" "$release/$archive"
  curl --fail --location --show-error --output "$archive.sha256" "$release/$archive.sha256"
  sha256sum -c "$archive.sha256"
  tar -xzf "$archive"
  ./panackelty/bin/panack --version
)

    macOS arm64 (Apple silicon)
    (
  set -eu
  release=https://github.com/sproates/panackelty/releases/download/v0.1.0-alpha.11
  archive=panackelty-0.1.0-alpha.11-macos-arm64.tar.gz
  curl --fail --location --show-error --output "$archive" "$release/$archive"
  curl --fail --location --show-error --output "$archive.sha256" "$release/$archive.sha256"
  shasum -a 256 -c "$archive.sha256"
  tar -xzf "$archive"
  ./panackelty/bin/panack --version
)

    A failed download or checksum stops the block before extraction; your terminal's shell settings stay unchanged. The checksum must report OK, followed by panack 0.1.0-alpha.11 (bytecode 9). If download or verification fails, resolve the error before continuing; do not extract or run the archive.

  2. Save the greeting

    Copy the complete greeting example above into a file named hello.panack beside the extracted panackelty directory. Keep the extracted directory together: it contains the whole toolchain.

  3. Check it, then run it

    Stay beside the extracted panackelty directory. These commands use its executable directly; you do not need to change PATH.

    ./panackelty/bin/panack --version
./panackelty/bin/panack check hello.panack
./panackelty/bin/panack run hello.panack

    The version reports panack 0.1.0-alpha.11 (bytecode 9). The program prints Hello, Ada. The answer is 42.

  4. Save a compiled program

    ./panackelty/bin/panack compile hello.panack -o hello.bc
./panackelty/bin/panack run hello.bc

    You get the same greeting through saved bytecode. For optional home-directory installation and PATH setup, or a build of the newer source, follow the full setup guide.

Keep going.

If a command is not found, use the explicit executable path shown above. If verification fails, stop before extraction. Keep the installed toolchain together and use its matching compiler and VM.
