Pass a small function where it is used

An anonymous function lets you write the callback alongside the operation that uses it. With values: [Nat], values.map((value) => value + 1) adds one to each element. The known element type supplies the parameter type. Without that context, write an annotation, such as (value: Nat) => value + 1.

The body determines whether an unmarked function is pure or has ordinary effects. Use async (...) => { ... } for an async callback. Creating a callback does not run it. Call a stored function using callback.call(...), or pass it to an API that expects a callback. Named functions still use @name when passed as values.

Retain the values a callback needs

A closure retains the immutable bindings it refers to. Those values remain available after the function that created the closure returns. Capturing a value does not capture a mutable variable that someone can silently change later. Implicit capture of mut bindings is rejected: pass the value explicitly, take an immutable snapshot, or use State for changes that calls should share.

Request writers, connections and other native resources cannot be captured. Receive them as callback parameters. The HTTP closure example captures its start instant and State handle; the request and response writer are parameters.

Make shared mutation explicit

Import stdlib/state, or stdlib/state/async from async code. Both expose create, read and update and use the same State[T] handle. All three operations are effectful, including creation. Await them with the async import.

create(initial) creates a cell. Copying its handle shares that cell. read(cell) returns an immutable snapshot. update(cell, callback) passes the current value to one pure callback, commits its result and returns the committed value.

The callback is called once. Competing reads and updates on that cell wait while the update is running. Other cells and runnable tasks can progress. Keep a read-modify-write operation inside the callback: reading first and replacing the value later can overwrite someone else's update.

The payload can contain immutable data, including records and collections. It cannot contain cells, callbacks, tasks or native resources. Closures can retain cells, so the shared mutation is visible at the state.update call. Handle equality compares cell identity, not the current contents.

The standalone counter demonstrates a pure transform and a retained cell without HTTP. It prints 1, 2, then 2.

Combine state and an async HTTP handler

The closure example keeps its start instant and request counter in an anonymous handler. The contextual example uses a named handler and passes the same values through an explicit context. Neither style is required by State; choose the one that makes your code clearest.

Both examples count committed increments for /status and report monotonic uptime. An unrecognised route does not increment the count. A request rejected before entering the handler is not counted either.

The handler increments before reading the clock. If that clock read fails, the response is HTTP 503 and includes the committed count. Failure to read the clock at startup prints an explanation and exits instead of starting an unusable service.

Cancellation or a trap before commit preserves the old cell value. Cancellation or response failure after commit does not undo it. A cancelled waiter never runs the callback. These rules define what the counter measures; it is not a count of successfully delivered responses. Restarting the server resets the count.

Keep external work outside an update

An update callback cannot read the clock, perform I/O, await work or read/update another cell. Do that work before or after the update. If the update needs a value obtained asynchronously, await it first and pass the resulting immutable data into the callback. There are no callback retries, public locks or multi-cell transactions in this API.

Complete example: A counter without HTTP

import stdlib/state as state

main(): Void {
  count = state.create[Nat](0)
  increment = (current: Nat) => current + 1
  next = () => state.update(count, increment)
  print(next.call())
  print(next.call())
  print(state.read(count))
}

Complete example: Request count and uptime with a closure

import http/server as http
import stdlib/time/async as time
import stdlib/state/async as state
import stdlib/host/async as host

async main(): Unit {
  arguments = await host.arguments()
  port = if arguments.len() == 0 { 8082 } else { arguments[0].parse_nat() }
  match await time.now() {
    Error(problem) => {
      reported = await host.stderr("Cannot start: the monotonic clock is unavailable.")
      await host.exit(1)
    },
    Ok(started) => {
      requests = await state.create[Nat](0)
      server = http.create_bound_server("127.0.0.1", port)
      server.get("/status", async (request: http.Request, response: http.ResponseWriter): Result[Unit,Str] => {
        total = await state.update(requests, (current: Nat) => current + 1)
        reading: Result[Instant,time.ClockError] = await time.now()
        match reading {
          Error(problem) => {
            response.status(503)
            response.send("Requests counted: ${total}; uptime unavailable: the clock could not be read.")
            Ok(())
          },
          Ok(now) => {
            elapsed = now.difference(started)
            seconds = elapsed.as_seconds()
            response.send("Requests counted: ${total}; uptime: ${seconds} seconds")
            Ok(())
          }
        }
      })
      match await server.listen() {
        Ok(done) => (),
        Error(problem) => {
          reported = await host.stderr(problem.message)
          await host.exit(1)
        }
      }
    }
  }
}

Complete example: Request count and uptime with a named handler

import http/server as http
import stdlib/time/async as time
import stdlib/state/async as state
import stdlib/host/async as host

record AppContext { started: Instant, requests: State[Nat] }

async status(context: AppContext, request: http.Request, response: http.ResponseWriter): Result[Unit,Str] {
  started = context.started
  requests = context.requests
  total = await state.update(requests, (current: Nat) => current + 1)
  reading: Result[Instant,time.ClockError] = await time.now()
  match reading {
    Error(problem) => {
      response.status(503)
      response.send("Requests counted: ${total}; uptime unavailable: the clock could not be read.")
      Ok(())
    },
    Ok(now) => {
      elapsed = now.difference(started)
      seconds = elapsed.as_seconds()
      response.send("Requests counted: ${total}; uptime: ${seconds} seconds")
      Ok(())
    }
  }
}

async main(): Unit {
  arguments = await host.arguments()
  port = if arguments.len() == 0 { 8082 } else { arguments[0].parse_nat() }
  match await time.now() {
    Error(problem) => {
      reported = await host.stderr("Cannot start: the monotonic clock is unavailable.")
      await host.exit(1)
    },
    Ok(started) => {
      requests = await state.create[Nat](0)
      server = http.create_bound_contextual_server("127.0.0.1", port, AppContext(started, requests))
      server.get("/status", @status)
      match await server.listen() {
        Ok(done) => (),
        Error(problem) => {
          reported = await host.stderr(problem.message)
          await host.exit(1)
        }
      }
    }
  }
}
